# @maka/mobile-rn

Maka Android client built with React Native.

## Status

Phase B / Module 1 — scaffold complete. This package is the React Native
workspace for the Android client. It does not touch `apps/desktop`, `scripts`,
or any existing `packages/*` source.

## Directory structure

```
apps/mobile-rn/
├── index.js                  # RN entry, registers App
├── src/
│   ├── App.tsx                # Root: SafeArea + NavigationContainer + RootNavigator
│   ├── navigation/
│   │   ├── RootNavigator.tsx  # Native Stack shell
│   │   ├── MainTabs.tsx        # Bottom tabs: 会话 / 设置
│   │   ├── types.ts            # Route param list types
│   │   └── index.ts
│   ├── screens/
│   │   ├── ChatScreen.tsx     # Shows "Maka Android"
│   │   ├── SettingsScreen.tsx
│   │   └── HomeScreen.tsx
│   ├── components/
│   │   └── Placeholder.tsx
│   ├── store/
│   │   ├── appStore.ts         # Zustand store (persisted via AsyncStorage)
│   │   └── index.ts
│   └── services/
│       ├── RuntimeHostClient.ts # runtime-host adapter placeholder
│       └── index.ts
├── android/                   # Android native project (generated by RN CLI)
├── ios/                       # iOS placeholder
├── __tests__/
├── metro.config.js            # monorepo watchFolders + extraNodeModules
├── babel.config.js
├── react-native.config.js
├── tsconfig.json
└── package.json
```

## Run commands

```bash
# from repo root
npm install                                    # installs workspaces incl. mobile-rn

# from apps/mobile-rn
npm start                                      # Metro bundler
npm run android                                # build + run on device/emulator
npm run ios                                    # (future) iOS
npm run typecheck                              # tsc --noEmit
npm run lint                                   # biome lint
npm test                                       # jest
```
